# Contributing to MiniCRM

Thanks for your interest in contributing to MiniCRM! The project follows a simple workflow:

1. **Fork** the repository and clone your fork locally.
2. **Create a feature branch** with a meaningful name, e.g. `feat/login-flow` or `fix/api-error`.
3. **Install dependencies** in both `backend` and `frontend` folders and verify the app runs.
4. **Follow the existing code style** and keep changes focused.
5. **Write clear commit messages** and include screenshots for UI changes when applicable.
6. **Submit a pull request** to the main repository explaining the purpose of your change.
7. **Respond to feedback**; maintainers may request revisions before merging.

For major changes or new features, please open an issue first to discuss the design.

By contributing, you agree that your work will be licensed under the project's MIT license (or the license specified in the repository).
